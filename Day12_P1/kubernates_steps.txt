Here's a complete Spring Boot + Docker example from scratch.

1. Create Spring Boot Application
Controller
package com.example.demo;

import org.springframework.web.bind.annotation.GetMapping;
import org.springframework.web.bind.annotation.RestController;

@RestController
public class HelloController {

    @GetMapping("/")
    public String hello() {
        return "Hello from Docker!";
    }
}
Main Class
package com.example.demo;

import org.springframework.boot.SpringApplication;
import org.springframework.boot.autoconfigure.SpringBootApplication;

@SpringBootApplication
public class DemoApplication {

    public static void main(String[] args) {
        SpringApplication.run(DemoApplication.class, args);
    }
}
application.properties
server.port=8080
2. Build the JAR

For Maven:

mvn clean package

Generated JAR:

target/demo-0.0.1-SNAPSHOT.jar
3. Create Dockerfile

Create a file named Dockerfile in the project root.

FROM eclipse-temurin:17-jdk

ARG JAR_FILE=target/*.jar

COPY ${JAR_FILE} app.jar

EXPOSE 8080

ENTRYPOINT ["java","-jar","/app.jar"]

For Java 8:

FROM eclipse-temurin:8-jdk

ARG JAR_FILE=target/*.jar

COPY ${JAR_FILE} app.jar

EXPOSE 8080

ENTRYPOINT ["java","-jar","/app.jar"]
4. Build Docker Image
docker build -t springboot-demo .

Verify:

docker images
5. Run Docker Container
docker run -d -p 8080:8080 --name spring-container springboot-demo

Check:

docker ps
6. Test Application

Open:

http://localhost:8080

Output:

Hello from Docker!
Useful Docker Commands
View Logs
docker logs spring-container
Stop Container
docker stop spring-container
Start Container
docker start spring-container
Remove Container
docker rm -f spring-container
Remove Image
docker rmi springboot-demo
Run on Different Host Port

If port 8080 is already in use:

docker run -d -p 4444:8080 --name spring-container springboot-demo

Access:

http://localhost:4444

This maps:

Host Port = 4444
Container Port = 8080

Spring Boot + Docker + Kubernetes Example (Step-by-Step)
1. Spring Boot Application
Controller
package com.example.demo;

import org.springframework.web.bind.annotation.GetMapping;
import org.springframework.web.bind.annotation.RestController;

@RestController
public class HelloController {

    @GetMapping("/")
    public String hello() {
        return "Hello from Spring Boot Kubernetes!";
    }
}
application.properties
server.port=8080
2. Build JAR
mvn clean package

Verify:

dir target

You should see:

demo-0.0.1-SNAPSHOT.jar
3. Dockerfile
FROM eclipse-temurin:17-jdk

ARG JAR_FILE=target/*.jar

COPY ${JAR_FILE} app.jar

EXPOSE 8080

ENTRYPOINT ["java","-jar","/app.jar"]
4. Build Docker Image
docker build -t springboot-k8s-demo .

Verify:

docker images
5. Test Docker Container
docker run -d -p 8080:8080 --name spring-container springboot-k8s-demo

Test:

http://localhost:8080

Expected output:

Hello from Spring Boot Kubernetes!

Stop and remove container:

docker rm -f spring-container
6. Kubernetes Deployment

Create deployment.yaml

apiVersion: apps/v1
kind: Deployment

metadata:
  name: springboot-deployment

spec:
  replicas: 2

  selector:
    matchLabels:
      app: springboot-app

  template:
    metadata:
      labels:
        app: springboot-app

    spec:
      containers:
      - name: springboot-container
        image: springboot-k8s-demo
        imagePullPolicy: Never
        ports:
        - containerPort: 8080
7. Kubernetes Service

Create service.yaml

apiVersion: v1
kind: Service

metadata:
  name: springboot-service

spec:
  type: NodePort

  selector:
    app: springboot-app

  ports:
  - port: 8080
    targetPort: 8080
    nodePort: 31111
8. Apply to Kubernetes
kubectl apply -f deployment.yaml
kubectl apply -f service.yaml

Check resources:

kubectl get deployments
kubectl get pods
kubectl get svc

Expected service:

NAME                 TYPE       CLUSTER-IP      PORT(S)
springboot-service   NodePort   xxx.xxx.xxx    8080:31111/TCP
9. Access Application

If using Docker Desktop Kubernetes:

http://localhost:31111
10. Troubleshooting
Pods not starting
kubectl get pods
kubectl describe pod <pod-name>
ImagePullBackOff / ErrImageNeverPull

Verify image exists locally:

docker images

You must see:

springboot-k8s-demo

If not:

docker build -t springboot-k8s-demo .
Check Logs
kubectl logs <pod-name>
Verify Service
kubectl get svc
Verify Deployment
kubectl get deployment
Clean Up
kubectl delete -f deployment.yaml
kubectl delete -f service.yaml

docker rm -f $(docker ps -aq)
