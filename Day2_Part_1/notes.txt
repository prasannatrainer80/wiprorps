External CSS : We can write code in .css file and can be called in multiple pages.

Assume, we need some of html files to be fragmented 
same css styling, then we need the help of external css.

how to make external css 

create a file as css1.css

p 
{
    color : blue;
}

div 
{
    color: orange;    
}
span 
{
    color : purple;
}

Assume, we need to call that in css1.html file, then

use <link /> 

<link type="text/css" rel="stylesheet" href="css1.css" />

Then the css file styling can be applied to specific html pages

Media Queries : 
________________

Used to make any website as tailored and responsive
This enables you to design the page as per the screen 
resolution. 

Example : Take gmail page, as it comes different
in laptop and different in Mobile. 

As per mobile screen size automatically app adjusts
the boundaries. 

They apply different CSS styles based on :
___________________________________________

	-> screen size
	-> device width
	-> height
	-> orientation
	-> resolution

You can define media queries using 

@media tag. 

example : 

@media(max-width:600px){
    body {
       color : red;
    }
}

The adv. with media queries website look and feel will not lost
as the access device getting changed.
