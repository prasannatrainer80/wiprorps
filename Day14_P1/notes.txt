Cloud Computing : 

     Is an internet-based computing service in which large groups of remote servers are networked to allow centralized data storage, and online access to computer services or resources. 

	Using Cloud computing, organizations can use shared computing and storage resources rather than building, operating, and improving infrastructure on their own.

Cloud Computing is a model that enables features as :
______________________________________________________

  -> Users can provision and release resources on-demand

  -> Resources can be scaled up and down automatically, depending on the load

  -> Resources are accessible over a network with proper security

  -> Cloud Service providers can enable a pay-as-you-go model, where customers are charged based on the type of resources and per usage. 

Types of Clouds :
__________________

1) Deployment Model

2) Service Model

There are various cloud models as

-> public cloud

	In Public Cloud, the third party service providers make resources and services available to their customers via internet. Customers data and related security is with the service provider's owned infrastructure.

-> private cloud

	It also provides almost similar features, but the data and services are managed by the organization or by the third party only for the customer's organization. In this type of cloud, the major control is over the infrastructure, so security related issues are minimized. 

-> hybrid cloud

    It is a combination of both private and public cloud, the decision to run on private or public cloud usually depends on various parameters like sensitivity of data and applications, industry certifcations

There are various types of service models available in cloud as

-> IAAS (Infrastructure as a Service)

	Provides basic infrastructure such as virtual machines, storage, networking and operating systems. You can manage OS, runtime, applications and data

Examples : AWS EC2
	   Microsoft Virtual Machines
	   Google Compute Engine

-> PAAS (Platform As as a Service)

	Provides a platform for developing and deploying applications. The cloud provider manages the infrastructure and operating system. 

	It manages 

	    Application Code and Data

Examples :

	Microsoft App Service
	Google App Engine
	Salesforce Platform Services
		
-> SAAS (Software as a Service) 
	Provides complete software applications over the internet. Users simply use the application. 

Examples : 

	Google Gmail
	Office 365
	Salesforce CRM
